# Android Forensics with ADB

![Banner Image](docs/Banner-Image.png)

A practical Android forensics and incident response project focused on forensic triage, artifact collection, and security analysis using **Android Debug Bridge (ADB)**.

The project provides a structured methodology, commands, and automation scripts for investigating Android devices from a forensic and defensive perspective.

---

## Objectives

This project aims to provide a practical workflow for:

* Android device forensic triage
* Device and system information collection
* Application enumeration and analysis
* Permission and security-control analysis
* Process and service investigation
* Battery and wakelock analysis
* Network and connectivity investigation
* Persistence detection
* Log collection and analysis
* APK acquisition and static analysis
* Identification of potentially suspicious applications
* Automated evidence collection and reporting
